# Cross-Breeding (Modal)

Subtitle: Combine mushrooms to create rare species

Breeding Mechanics
- Combine two mushroom NFTs to create a new hybrid species. Each parent contributes traits like color, pattern, rarity, and special abilities.

Genetic Traits
- Mushrooms carry genetic markers that determine offspring characteristics. Rare traits have lower inheritance rates, making legendary mushrooms highly valuable.

Rarity System
- Common + Common = Uncommon (70%), Rare (25%), Legendary (5%). Uncommon + Rare = Rare (60%), Legendary (30%), Mythic (10%). Breeding costs scale with parent rarity.

Cooldown & Economics
- Each mushroom has a breeding cooldown (24-72 hours based on rarity). Breeding requires token burns, creating deflationary pressure while rewarding collectors.

🧪 Breeding Example
- Parent 1 — Purple Mystic (Rare)
- Parent 2 — Pink Celestial (Uncommon)
- Offspring — Twilight Hybrid (Legendary)
